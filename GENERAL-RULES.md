# General build rules

This are rules for the General sub agent to follow

1. Always read PRD.md, DESIGN.md and references folder before the planning stage of every phase
2. Be Faithful to the references.
3. DO NOT USE REFERENCES AS TECH EXAMPLES.
4. Execute the plan given by the Plan agent.
5. Always commit the changes on the with a meaningful message after a Phase is completed
6. Never commit changes when the app is not building
